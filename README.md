# Nordic Gaming Browser

Sitio público de Nordic Gaming Browser, publicado con GitHub Pages:
https://noordic.github.io/nordic-gaming-browser/

## Contenido

- `index.html`: presentación en español, funciones, configuración y contacto.
- `styles.css`: diseño adaptable a escritorio y móvil, navegación por teclado y soporte para movimiento reducido.
- `assets/`: logo de Nordic y capturas de su interfaz.

Información, planes, precios y acceso: https://discord.gg/AZUxGHRaNY

## Mantenimiento

La revisión del 15 de septiembre de 2026 se basa en las funciones de la edición
comercial de Nordic. No anuncia una versión descargable ni fija precios;
la disponibilidad se consulta en Discord.

Las capturas de Inicio y Opciones avanzadas corresponden a la interfaz de Nordic
revisada el 14 de septiembre de 2026. Son imágenes estáticas, ampliables mediante
sus enlaces. El sitio no incorpora código del navegador ni datos de usuarios.

Para futuras actualizaciones:

1. Comprobar las funciones contra la edición comercial vigente.
2. Mantener fuera las funciones exclusivas de otras ediciones y las que aún no
   estén autorizadas para Commercial.
3. Revisar las capturas antes de publicarlas para evitar datos personales.
4. Comprobar enlaces, imágenes, metadatos y presentación móvil.
5. Publicar en la rama configurada de GitHub Pages y verificar el despliegue.

Es un sitio estático sin dependencias ni paso de compilación. Se puede previsualizar
con cualquier servidor HTTP local que sirva esta carpeta.
